# 🚕 Dynamic Ride Pricing Predictor (Прогнозирование Динамической Цены Поездок)

Проект реализует систему машинного обучения для **прогнозирования фактической стоимости поездки** (Booking Value) на основе базового тарифа и множества динамических факторов, таких как время суток, пробки, местоположение и рейтинг водителя/клиента.

## 💡 Описание Проекта

Основная цель проекта — построить модель, которая предсказывает цену на поездку, учитывая динамические данные

### Используемые Технологии
* **Язык:** Python
* **Библиотеки:** `pandas`, `numpy`, `scikit-learn`, `joblib`, `RandomForestRegressor`

## ⚙️ Обучение Модели (`train_model.py`)

Скрипт выполняет **предобработку данных**, расчет **оптимального линейного тарифа**, генерацию признаков (включая `delta` как целевую переменную) и **обучение модели** для каждого типа транспорта.

**Запуск обучения:**
```bash
python train_model.py
```
⚠️ Важно:
Убедитесь, что файл данных 1.csv находится в корневой папке проекта,
а также создана папка models/ для сохранения обученных моделей.

## 🔮 Прогнозирование Цены (predict_price.py)

Скрипт загружает выбранную модель, запрашивает дистанцию поездки и выводит:

1. прогноз цены,

2. цену за километр,

3. сравнение с базовым тарифом и статистикой из датасета.

Запуск прогнозирования:
```bash
python predict_price.py
```

## 📊 Результаты и метрики
**MAE**	- Средняя Абсолютная Ошибка (Mean Absolute Error). Показывает среднюю разницу между предсказанной и фактической ценой.
**R²** - Коэффициент детерминации. Показывает, какую долю дисперсии целевой переменной объясняет модель. Значение, близкое к 1, указывает на хорошее качество.

**expected_fare** — это базовая тарифная цена поездки, которую мы рассчитываем напрямую из данных с помощью простой линейной регрессии:

`expected_fare = BASE_FARE + FARE_PER_KM × Ride Distance`

- То есть expected_fare — это базовый ориентир, может предсказывать цену выше или ниже него, учитывая дополнительные признаки.
